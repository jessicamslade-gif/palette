# Link Catalog

A personal web app for saving links into projects and exporting them as a
polished PDF catalog (with titles, images, and image sizes).

## What's here
- Next.js web app (pages + API routes)
- Supabase (Postgres) for storage
- PDF export built with pdf-lib

See the deployment steps Claude gave you in chat for how to get this live
on Vercel + Supabase for free.
